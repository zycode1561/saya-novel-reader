# 云端小说阅读器

## 功能

- 支持上传和阅读 TXT、Markdown、EPUB，单个文件最大 50 MB。
- 云端书架管理藏书，支持继续阅读、下载原文件和删除书籍。
- 支持在线搜书、书源管理和添加到云端书架。
- 提供章节目录、章节筛选和书内关键词搜索。
- 搜索或从目录跳章后，可一键返回原阅读位置，支持恢复长段落中的阅读位置。
- 支持上下滚动、左右翻页，以及点击正文中间显示或收起导航。
- 可调整字体、字号、行距、首行缩进和阅读主题，设置即时生效。
- 阅读进度在电脑和手机之间同步，并提供同步状态、重试与冲突选择。
- 底部左侧显示同步云朵，右侧显示全书进度百分比；章节导航独立显示在下方。
- 已打开的书籍可在本机缓存，支持离线继续阅读，联网后同步进度。

## 使用说明

### 打开与登录

打开[云端阅读器](https://saya-novel-library.zycode1561.chatgpt.site)，使用拥有站点访问权限的账号登录。电脑和手机可使用同一账号接着阅读。

### 上传和打开书籍

1. 在“书库 → 云端书库”中点击“上传书籍”，选择 TXT、Markdown 或 EPUB 文件。
2. 等待上传完成，点击书籍开始阅读。
3. 下次进入书库时，点击“继续上次阅读”回到上次的位置。
4. 在书籍的“更多操作”中查看详情、下载原文件或删除书籍。

“本机书架”用于在当前设备打开本地文件；需要跨设备访问时，请上传到云端书库。

### 书架显示与封面

- 在书架内容区选择“封面”或“列表”，当前设备会记住显示方式。列表适合快速浏览较多藏书。
- EPUB 上传或打开时提取自带的 JPEG、PNG 或 WebP 封面，并生成小型 JPEG 缩略图；云端书籍的缩略图也会同步，其他设备无需下载整本书即可显示。已有 EPUB 下次打开后补齐封面。
- 没有可用图片的书使用固定配色与纹样的文字封面，封面与列表视图均独立显示完整书名，不依赖封面上的文字识别。封面提取失败不影响正文阅读。

### 阅读与导航

- 在“阅读设置 → 阅读与导航”中选择上下滚动或左右翻页。
- 左右翻页时可滑动屏幕，或点击正文左右两侧翻页。
- 关闭“导航栏常驻”后，点击正文中间可显示或收起工具栏和下方的章节导航。
- 通过“目录”跳转章节，也可输入章节名或序号筛选。
- 通过“书内搜索”查找关键词，点击结果回到对应正文。在线阅读时，搜索范围为当前已加载章节。

### 返回原阅读位置

从搜索结果或目录跳转后，底部状态行会显示“回到刚才”。点击可回到跳转前的位置；连续查阅多个章节时保留最初的位置。点击旁边的关闭按钮可放弃返回。该入口仅在当前阅读会话中保留，返回、关闭或切换书籍后收起。普通翻页不会生成返回记录。

### 调整阅读外观

打开“阅读设置”，选择字体、字号、行距、缩进和主题。修改立即生效，并保存在当前设备上。

### 在线搜书

在“搜书”中启用或导入可用书源，输入书名或关键词进行搜索。打开结果后可在线阅读，也可添加到云端书架。添加期间请保持页面打开，并仅使用有权访问的内容。

### 云端与本机状态

书架和最近在读卡片分别显示保存位置与本机可用状态：

- **仅本机**：文件未关联云端书库，换设备前请在云端书库上传原文件。
- **已存云端**：可在其他设备登录后打开。
- **本机可离线**：当前浏览器中检测到该入口需要的完整正文或原文件。清除浏览器数据后需要重新下载或导入。
- **需联网下载／需联网阅读**：当前设备尚未下载原文件，或该记录属于在线书源。
- 本机正文缺失、缓存检查失败和云端关联无法确认时，会显示对应提示，不会仅凭阅读记录标为可离线。

### 同步与离线阅读

- 云朵内的绿色勾表示进度已同步；箭头表示等待同步或正在同步。
- 点击云朵可查看最近同步时间、立即同步或重试。
- 出现进度冲突时，可选择采用云端位置或保留本机位置。
- 离线使用前，请先联网打开所需书籍，让当前设备完成缓存。离线进度会保存在本机，恢复网络后继续同步。

### 继续阅读与导航（2026-10-31）

- 最近在读卡片整张可点击，也可用键盘聚焦并打开。卡片显示保存的章节；本机有对应进度时同时显示已读百分比，云端记录较新时优先显示云端章节。没有可用记录时显示恢复位置提示。
- 书架导航提供“书架、找书、设置”；进入阅读后提供“书架、目录、书内查找、设置”。
- 手机（阅读器宽度不超过 600px）的阅读工具位于底部；保留原有导航常驻或点击正文显隐的设置。桌面仍使用顶部工具栏。

### 全屏阅读与临时工具栏（2026-10-31）

正文使用完整阅读区域。点击正文中央唤起顶部返回栏和底部工具栏，再点中央收起。工具使用不透明覆盖层，出现时暂时遮住边缘文字，收起后没有预留空白；显隐不改变正文尺寸，不触发重新分页或位置恢复。桌面侧目录同样覆盖显示。已有“导航栏常驻”偏好保留，可在设置中关闭以使用点击显隐。

同步云朵、全书阅读进度及“回到刚才”状态在收起工具后仍保留。仅为底部状态行保留固定的小块空间，上下操作工具继续覆盖显示；显隐时不改变正文尺寸。

### 在书架中找书（2026-11-01）

- “搜索我的书架”按书名或文件名即时筛选当前云端／本机页签。支持书名片段、空格分隔的多个关键词，忽略英文大小写和全半角差异。
- 搜索时显示匹配数量，并收起最近在读卡片。没有匹配时提示更换关键词或清空；清空后恢复完整书架及原排序。两个页签的搜索词在本次页面会话中分别保留。
- 书架页面按 Cmd/Ctrl+F 聚焦书架搜索；搜索框中的 Escape 清空关键词。
- 云端卡片优先显示已读百分比或已保存章节，采用较新的本机／云端记录；百分比未知时不估算。文件格式和大小仍在书籍详情中。
