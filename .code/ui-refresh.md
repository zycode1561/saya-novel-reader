# 阅读器 UI 优化 · 2026-10-25

参考：https://github.com/oil-oil/oil-ui 。借鉴产品任务优先、统一视觉语言、实际截图检查和减法的方法；没有安装该 Skill。

方向：安静的私人书房。暖纸背景、墨绿主操作、宋体书名、低饱和书封。保留原有书房名称、阅读入口、目录、搜索、设置及同步流程。

## 实现

- `public/reader/reader-ui.css` 是站点视觉层，在现有阅读器的内嵌样式之后加载。更新上游阅读器包时保留该文件及入口链接。
- 桌面导航收拢，手机双列书封；360px 以上显示导航文字，更窄屏幕保留图标和可访问名称。
- 最近在读使用墨绿区域，书封采用纸面色和轻微悬停反馈。尊重系统减少动效设置。
- 目录、搜索、设置继承统一的纸面和控件样式；保留字号、字体、行距及护眼主题偏好。
- 修复窄屏书籍菜单向上超出滚动区的裁切，定位时同时约束横向和纵向范围。
- Service Worker 更新缓存版本并包含新 CSS；入口资源带版本号。

## 验证

- 在本机隔离预览中使用 8 本虚构书籍，未上传或改动用户的真实藏书。
- 实际浏览器检查桌面 1280×720、手机 390×844 和窄屏 320×740；检查日间与夜间书架、设置、目录和搜索。
- 打开书籍、继续阅读、目录跳章、关键词搜索及搜索结果回到正文通过。
- 320px 下书籍菜单完整位于书架滚动区内，没有横向溢出。
- 主题设置刷新后保留；生产构建、JS 语法检查、Git 空白检查和既有阅读顺序检查通过。
- 未在真实手机设备测试，未重做线上上传、删除和跨设备同步测试。

复现本机视觉检查：在站点目录运行 `node .code/ui-preview.mjs`，访问其输出地址。预览接口只操作内存数据，关闭进程即结束。
