# 阅读器 UI 优化 · 2026-10-25

参考：https://github.com/oil-oil/oil-ui 。借鉴产品任务优先、统一视觉语言、实际截图检查和减法的方法；没有安装该 Skill。

方向：安静的私人书房。暖纸背景、暖灰墨黑主操作、宋体书名、低饱和书封。保留原有书房名称、阅读入口、目录、搜索、设置及同步流程。

## 实现

- `public/reader/reader-ui.css` 是站点视觉层，在现有阅读器的内嵌样式之后加载。更新上游阅读器包时保留该文件及入口链接。
- 桌面导航收拢，手机双列书封；360px 以上显示导航文字，更窄屏幕保留图标和可访问名称。
- 最近在读使用暖灰区域，书封采用纸面色和轻微悬停反馈。尊重系统减少动效设置。
- 目录、搜索、设置继承统一的纸面和控件样式；保留字号、字体、行距及护眼主题偏好。
- 修复窄屏书籍菜单向上超出滚动区的裁切，定位时同时约束横向和纵向范围。
- Service Worker 更新缓存版本并包含新 CSS；入口资源带版本号。

## 配色调整

用户不喜欢绿色，主色调整为暖灰、墨黑，封面采用灰米、浅棕和蓝灰。日夜主题中的目录、搜索标记、设置选中状态、在线搜索和同步图标一并统一。原有可选护眼绿正文主题保留。

## 苹果风格改版 · 2026-10-25

根据 `apple-design` 与 `emil-design-eng` 技能，改用系统字体、灰白背景、蓝色主操作、磨砂工具栏和圆角分组设置。深色模式采用石墨黑表面，书封保留低饱和蓝、米色和淡紫色。书库分类改为分段控件，继续阅读使用白色卡片。按钮提供即时按压反馈，并适配减少动效、减少透明度及增强对比度偏好。

改动仅涉及站点视觉层、入口样式版本和 Service Worker 缓存版本；正文的字体、字号、护眼主题及分页参数沿用既有设置。

验证：生产构建、JS 语法与 Git 空白检查通过；使用隔离预览的虚构书籍检查桌面浅色/深色、390px 与 320px 布局、手机设置、目录、书内搜索，以及继续阅读、目录跳章、搜索结果返回正文。320px 书籍菜单完整位于视口内。没有在真实手机上验证，也未重测线上上传、删除或跨设备同步。

## 工具页空间修复 · 2026-10-25

- 目录、书内搜索、阅读设置和在线搜书合并返回栏与大标题；书源管理沿用同一个 `PanelHeader`。返回箭头紧邻标题，保留 44px 点击区域和“返回”可访问名称。
- 工具栏桌面从 76px 缩为 56px，手机从 68px 缩为 52px；缩减工具页上方内边距和搜索框周围留白。
- 大文件模式等书籍阅读提示只在正文页显示，宿主操作反馈仍保留。
- 隔离预览可通过 `READER_QA_LONG_BOOK=1 node .code/ui-preview.mjs` 生成 1900 章、超过 10MB 的虚构书籍，复现用户截图的长目录场景。
- 浏览器验证：390×660 下目录列表高 398px，标题栏高 44px；检查目录筛选、跳到第16章、书内关键词结果、返回正文、在线搜书和书源管理返回；320×480 下设置与书源管理标题完整且没有横向溢出。未在实体 iPhone 上测试。

## Arc 交互细节优化 · 2026-10-25

参考：https://uiarc.dev/ 、https://uiarc.dev/components/tabs 、https://uiarc.dev/components/dropdown-menu 。保留苹果风格与紧凑标题栏，减弱大面积阴影，统一细边框和控件圆角。手机最近在读卡片从 172px 最小高度调整至 140px，允许长标题自然增高。

- 导航、云端/本机分类和行距控件使用独立的选中背景，以 180ms transform 过渡到新位置；快速改选从当前显示位置接续，窗口变化时重新对齐。背景不参与布局、不接收输入。
- 工具页和书架分类切换使用 120ms 短淡入。正文翻页、目录列表、搜索结果不增加等待或逐项入场。
- 书籍菜单从触发位置以 180ms 轻微缩放和淡入展开，120ms 收起；可在收起途中重新打开。同步详情使用轻量进入效果，保留原同步逻辑。
- 发现并修复菜单在短屏中覆盖触发按钮的问题：根据上下剩余空间定位，限制菜单高度并内部滚动。Escape 立即关闭，连续点击不会落到被遮住的删除操作上。
- 键盘操作、减少动效模式及无 WAAPI 支持的浏览器直接更新状态；保留已有减少透明度和增强对比度适配。没有添加依赖。

验证：`.code/reader-motion.test.cjs` 检查可见状态退出、动画中断、关闭后快速重开、键盘、减少动效、浏览器降级和菜单碰撞定位；JS 语法与 Git 空白检查通过。实际浏览器检查桌面、390×660 与 320×480、深浅主题、云端/本机切换、连续改选行距、菜单与 Escape、搜索与返回原位置、同步详情。1900 章目录在 390×660 下保留 398px 可用列表高度，手机工具栏仍为 52px。浏览器无运行错误；没有在实体手机上测试，也未重测真实上传、删除及跨设备同步。
